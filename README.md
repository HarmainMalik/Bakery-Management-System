# Sweet Bakery Management System 🍰

A desktop bakery management application built with **C#**, **Windows Forms**, and **Object-Oriented Programming**.

## 🛠️ Technologies

- C#
- .NET
- Windows Forms
- Visual Studio
- Object-Oriented Programming
- Repository-Based Data Access
- Layered Architecture

## ✨ Features

- 🔐 Role-based authentication
- 👑 Owner admin approval
- 🧑‍💼 Admin product management
- 📦 Inventory management
- ⚠️ Low-stock monitoring
- 📅 Expiry tracking
- 🛒 Customer purchasing
- 🧾 Receipt generation
- 📊 Sales reporting
- 🔄 Automatic inventory updates

## 👥 User Roles

### Owner
- Approve/Deny admin requests
- Manage admin access

### Admin
- Add, update, and delete products
- Update prices
- Monitor inventory
- Track low-stock products
- Monitor expiry dates
- View sales

### Customer
- Browse products
- Select quantities
- Purchase products
- Receive purchase receipts

### 💡 OOP Concepts
Encapsulation
Classes & Objects
Separation of Responsibilities
Service-Based Business Logic
Repository Pattern
Layered Architecture
Event-Driven Programming

###🔧 Core Services
- AuthService
- ProductService
- AdminService
- CustomerService
- SalesService
  
###🖥️ UI
Built with Windows Forms, providing separate workflows for:

- Owner
- Admin
- Customer
  
###🎥 Project Demo
